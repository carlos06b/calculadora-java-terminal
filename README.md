# Calculadora Java Terminal

Projeto simples desenvolvido em Java para praticar conceitos iniciais da linguagem.

A aplicação recebe dois números pelo terminal, utiliza uma classe `Calculadora` para realizar a soma e exibe o resultado para o usuário.

## Objetivo

Praticar conceitos básicos de Java, como:

- Criação de classes
- Criação de métodos
- Instanciação de objetos
- Entrada de dados com `Scanner`
- Exibição de resultados no terminal
